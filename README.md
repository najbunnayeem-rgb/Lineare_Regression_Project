### Linear Regression Projects

A hands-on collection of Jupyter notebooks for learning and practicing linear regression with Python and scikit-learn. The project explores three approaches, from fitting a straight line to modeling curved relationships.

## Notebooks
1simpleLinearRegression.ipynb - Uses one input feature to predict a target with a straight-line relationship.
2MultipleLinearRegresiion.ipynb - Uses multiple input features to predict a target.
3PolynomialRegression.ipynb - Uses polynomial features to model a curved relationship.

## Datasets
economic_index.csv - Economic data for practicing regression.
height-weight.csv - Height and weight data for exploring how two variables relate.
